# 洛阳伽蓝记 — 公版原文抽样数据集

- 原书：洛阳伽蓝记
- 公版依据：作者卒年距今远超 50 年，原文公版。
- 抽样：从正文起点连续取完整卷/章，累计达全书正文汉字数 45% 即止（确定性、可复现、只减不超）。本次实现率 32.5%。
- 剥离：来源整理本的现代标点、注释、译文、校记、书影、出版信息一律不收，仅存原书正文汉字。
- 边界：本数据集不含扫描页图像与整理本独创内容；仅供古籍数字化方法与文本质量研究。

## 文件

- public_domain_sample.json —— 抽样正文（章/段结构，含印刷页码映射）
- structure_data.json —— 章目录与篇幅元数据（现代著作书仅提供本件）
