# 硬规矩（实盘踩坑总结）

这些规则来自 44 本书、17,513 页的实盘返工，违反任意一条都会造成不可逆数据损伤。

## 数据写入

1. **写入前必留快照**：`book.json.bak_<yyyyMMdd_HHMMSS>_<说明>`；书内最多 3 份，多的移出归档。
2. **一个批次一次写入**：不要边改边写，改完先 dry-run 打印 diff，确认后一次落盘。
3. **按内容前缀定位块**：脚本用「块的文字前缀 + 类型 + 页」定位，并 `assert` 全书唯一；
   绝不用硬编码下标（下标会随前面的增删失效）。
4. **`book.json` 固定 `indent=1`**，UTF-8；diff 可读性优先。

## 内容口径

5. **图注照录原页印刷文字，不拟题**。原页无图注就置 `captionDisplay=false`（计入豁免预算，不得滥用）；
   组合图可共用一条印刷图注。
6. **英文/拉丁原题照录**：章名英文题作为独立段落块紧随「第N章 章名」，不并进标题。
7. **不擅自加「豁免」**：`figure_caption_exempt` 之类开关只对已登记的书生效，不能给非豁免书开后门。
8. **不删图不留证**：删任何图/块前先裁原页留证，并逐块过目；批量脚本删完必须抽查。

## 坐标与图像

9. **OCR 坐标空间固定 1800×2558**，PDF 渲染 `fitz.Matrix(3,3)`。
10. **裁图前缩放坐标**：`(page.rect.width/1800, page.rect.height/2558)`；否则 PyMuPDF 报
    `Invalid bandwriter header dimensions/setup`。
11. **不从缩放图量坐标**：Read/预览工具的降采样图只用于「看」，量尺寸必须用原分辨率渲染。

## 流程与协作

12. **单写者**：同一本书同一时刻只有一个进程/人写 `book.json`；改前确认没有别的批次在跑。
13. **中文文件名用 `os.listdir`**，不要用 `glob`（书名含 `[` `]` 时 glob 会静默漏匹配）。
14. **质检数字由工具重算**：页数/字数/章数/图数/配注数一律跑脚本，禁止手写或复制历史报告。
15. **改指标先报备**：用于验收的指标定义锁定；改阈值/改自检脚本必须在台账写明原因与前后对比。

## 返工教训

- 某轮批量删「重复图」脚本按图片哈希去重，误删 85 张真图（不同图恰好同哈希/同尺寸），
  返工重裁 56 张、合并 16 张、确认 13 张真重复。**删图必须逐张过目。**
- 章首页「标题+英文题+首段」被 OCR 融成一块时，不要整体当标题保留，也不要整块删；
  拆成「标题 → 英文题段落 → 首段」三段并核对页码。
- 修复重建块后必须做字符级校对（引文、拉丁专名、省略号），OCR 讹字不会因结构修好而消失。
