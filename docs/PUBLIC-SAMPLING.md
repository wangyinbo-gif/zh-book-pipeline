# 公版原文样本的导出与复验方法

工具能把扫描本变成结构化书稿，但**「能转换」不等于「能公开」**。本仓库不分发任何书籍正文
（理由见 [DATASET.md](DATASET.md)）；若要对外提供「公版原文样本」，必须先过一套固定的剥离 + 抽样 + 复验流程。
这篇是方法论，不含任何具体书目。

## 一、先做版权判定，再谈抽样

判定按「作品」与「整理本成分」两层拆开，三档处理：

| 档 | 条件 | 可对外内容 |
|---|---|---|
| 可给原文样本 | 原作者卒年距今超过保护期（公版），**且**整理本成分能逐条剥离 | 剥离后的原文片段（含章名/页码映射） |
| 只给结构数据 | 现代著作、版式/图片权利待确认 | 章节树、页数、字数统计——**不含正文** |
| 不公开 | 作品仍在版权保护期内 | 无（内部使用） |

两条纪律：

1. **判定写在样本目录的 README 里**，注明依据（作者卒年、剥离了哪些整理成分）与「未发布」状态；
2. **扩大公开范围前必须人工复审并逐本签字**——工具只保证「剥干净」，不保证「这本可以公开」。

## 二、剥离规则（六条，逐条可验）

公版古籍的**原文**公版，但整理本里的现代成分另有权利。导出时按块逐条剥离：

| # | 剥离对象 | 做法 | 判据 |
|---|---|---|---|
| 1 | 现代标点与符号 | 删除全/半角现代标点、圈码、上下标数字、阿拉伯数字、西文、空白 | 古籍原文以汉字书写数字、不用现代标点 |
| 2 | 注释 | `type=note` 整块剔除；行首圈码/括号码注段剔除；注区内「词头：释义」短注剔除 | 注码形态 |
| 3 | 译文段 | 段首「【译文】/译文：」及其 OCR 变体起，按**区（zone）状态机**吞到下一标题 | 状态机，不是单行正则 |
| 4 | 校勘记/编者按 | 含「校记/底本/参校本/按」且短于 200 字剔除；夹注合并段**存疑整段剔除** | 宁缺勿混 |
| 5 | 图版 | 不导出任何 `assets`；`figure` 块 → 一条「此处原书有图」占位 | 图片权利独立于文字 |
| 6 | 目录/版权/广告页 | 前置文献章整章排除；行首「目录/插图/附图」行剔除；含 URL/书单/水印段剔除 | 版式行 + 广告特征 |

区状态机是关键：注区、译区往往**跨段、跨页**，只看单行会把「小标题」「内嵌注码」误当注释吞掉，
或把续接的译文段当正文留下。

## 三、抽样规则（确定性、可复现）

- 正文起点 = 第一个非「前置文献」章（卷首/前言/目录/版权/附录整章排除）。
- 从起点起**按章连续累计**汉字数，达到「该书正文总汉字数 × 目标比例」时，
  停在**最后一个不越界的完整章**——宁可少给，不给半章。
- 首章单独就超阈值时取完整首章，并在样本的 `sampleRule` 字段里注明原因。
- **无随机**：同一输入两次导出必须字节一致，这样「样本变了」只可能是书稿变了。
- 目标比例由人工拍板并写进样本 README；工具不接受「随手调大」。

## 四、出口复验（导出后再扫一遍）

导出脚本自带 `--verify`，扫全部导出 JSON 并断言：

1. 现代标点 **0**、阿拉伯数字 **0**、圈码/注号 **0**；
2. 「译文」标记 **0**、注区/校记残留 **0**；
3. URL / 书单 / 站点水印 **0**；
4. 结构包（第二档）**不含任何正文文本字段**；
5. 图版只有占位，无 `asset` 路径。

复验必须**在导出产物上跑**，不是在被剥离前的书稿上跑——这是唯一能证明「剥干净了」的环节。

## 五、为什么导出脚本不在本仓库

`tools/export_public_sample.py` 里是一张**书目配置表**：每本书的目录前缀、字数、抽样比例、
版权判定依据。它同时包含「谁持有哪些书」与「对每本书的版权结论」，属于内部台账与个人藏书信息，
不随公开仓库分发；单书的修复脚本（文件名即书名）同理。

本仓库保留的是**能复现方法的层面**：块 schema、剥离判据、抽样与复验规则（本文）、
竖排识别与页级闸（见 [VERTICAL-OCR.md](VERTICAL-OCR.md)）。

## 六、复用清单

要把这套流程用在自己的书库上：

1. 先出版权判定表（三档），落到每本样本目录的 README；
2. 按第二节六条写剥离器，**逐条**用假数据单测（每条一个用例，别只测整体）；
3. 抽样用确定性贪心，输出后跑出口复验；
4. 任何「比例调整 / 新增可公开书」都要重新走人工复审，不要改脚本默认值。
