# 质检模型与验收命令

「程序绿灯」不等于「内容对」。本项目把质量分成三层，只有第三层算深审。

| 层 | 做什么 | 谁做 | 能否自动化 |
|---|---|---|---|
| ① 程序绿灯 | gate / textcheck / proofread / coverage / structure 全过 | 脚本 | 是 |
| ② 逐页机器对照 | OCR 文本 vs 书稿文本，逐页覆盖率、偏移、丢文 | 脚本 + 抽样人工 | 半自动 |
| ③ 逐页人工目视 | 对照原页看图注、断句、表格、跨页 | 人 | 否 |

## ① 程序门禁

```bash
python tools/pipeline.py recheck  "<书名>"     # gate：结构不变量
python tools/pipeline.py coverage "<书名>"     # 逐页 OCR↔书稿覆盖率
python tools/pipeline.py structure "<书名>"    # 章起点是否落在标题块
python tools/proofread.py "books/<书名>"       # 校对清单（必看/参考）
python tools/realign_chapters.py "books/<书名>"  # 章边界重对齐，回退数应为 0
python tools/booklist.py                       # 全库数字汇总（页/字/章/图/配注）
python -m unittest discover -s tools           # 诊断/复核工具回归（临时目录，不写书库）
```

常见不变量：

- **图注配对**：`figure` 块 100% 有图注（或显式豁免且计数在预算内）
- **章边界**：`startBlock` 必须指向 `heading`；realign 回退 0
- **结构**：无空段、无乱序页、跨页续段的 `pages` 连续
- **碎片**：正文中「句中断裂」「段首标点」「重复段」在阈值内
- **水印/广告页**：不得作为正文块残留

## ② 覆盖率对照

按页统计 OCR 字数与书稿字数之比：整页为 0 或远低于左右邻页 = 疑似整页丢文/串行。
报告输出「必看」与「参考」两级；参考级（封面、版权页、图版目录、索引）可核销，但必须写理由。

## ③ 人工目视

- 图注、图内文字、表格：只看裁图不算，必须对原页；
- 疑似串行/丢行：裁原页 3× 图逐行核；
- 任何「删块/删图」动作：先留证（裁图 + 前后 book.json 快照），再逐块过目。

## 校对清单分级

`proofread.py` 把可疑处分为：

- **必看**：大概率真问题——正文句子被切断、段落以标点开头、重复段、乱码、图注吞正文、整页未进书稿
- **参考**：结构性噪声——目录页断行、页眉页脚数字、编号行、极短块、可疑拉丁串、占位图注、前置页/整页图版造成的低覆盖率

分级只影响阅读顺序，不改变 `issues` 条目数量，因此不可拿分级当「减少问题数」的手段。

## 指标口径

- 指标定义一旦用于验收就**锁定**；改自检脚本前先报备，否则会出现「改指标 = 变绿」。
- 已知无效指标：**4-gram 与 OCR 一致度**不能当照录正确性指标——修对讹字必然降低与 OCR 的一致度。
- 字数、图数、配注数一律由工具重算（`booklist.py` / 各阶段脚本），不手写、不复制旧报告。

## 修复纪律

1. 改 `book.json` 前先备份（`book.json.bak_<时间戳>_<说明>`，书内 ≤3 份，多的移出归档）。
2. 一批改动一次写入；脚本按「内容前缀」定位块并 `assert` 唯一，禁止硬编码下标。
3. 每个修复在台账写：页码、块 id、原文字、改后文字、依据（原页裁图路径）。
4. 删图/删块必须留证并逐块过目——曾因批量删图误删 85 张真图，返工代价远高于多看一眼。
